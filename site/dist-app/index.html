Questions

What happens when I install a kit?

Claude Code copies the kit's files and registers its skills, agents and hooks. Each kit page lists the hooks it runs and what it reads, writes and sends, and the source is in the repository if you want to read it first.

How do updates reach me?

Run /plugin marketplace update praxikit, then /reload-plugins. Kits use semantic versions and keep a changelog; the updates page shows what changed since your version.

What do the build checks on a kit page mean?

They are computed from the files when the site is built: the manifest is complete, the changelog matches the version, the scripts contain no network code. They show the kit is consistent. They are not a security audit.
