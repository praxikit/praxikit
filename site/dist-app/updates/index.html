Updates

Check whether you are up to date, and see what changed in each release.

Am I up to date?

Pick the version you have to see only what changed since. Or run /keel:status, which prints a link that fills this in.

Fill this in for me

A web page cannot see what is installed on your machine, so paste the output of claude plugin list (or claude plugin list --json) and the version is picked for you. The text stays in your browser.

Update with:

/plugin marketplace update praxikit

then /reload-plugins.
