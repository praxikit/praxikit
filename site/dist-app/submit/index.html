Submit a kit

Free. Paste the link to a public GitHub repository, yours or someone else's. We read its name, owner, licence and README from GitHub, so you do not need to describe it.

You will sign in with GitHub (only your username is read) and confirm on the next screen. Your link is passed along so you do not paste it twice.

Prefer GitHub issues, or the app is down? Open an issue instead.

What happens next

  1. The checks run. A maintainer asks for the full read-only scan: it reads the public repository at one commit without running or installing anything, and reports licence, secret-like strings, code that runs automatically, network access, binaries and hidden instructions. It reports what it found and never says a kit is safe.
  2. A person reads the report and decides. The result is a starting point, not a decision. Only GitHub links can be checked automatically.
  3. If it is listed, the listing is pinned to the commit that person reviewed, and a daily check marks it Changed since review if the repository moves on. It becomes one of the owner's picks only if the owner uses it.

Nothing is listed for payment, and listing is not a promise that a kit is safe. Read the policy for how reports and removals work.
